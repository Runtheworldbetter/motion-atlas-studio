# Paper Shaders in Atlas

The Originals collection includes the actual Metaballs and Warp GPU renderers and ten original presets from Paper Shaders 0.0.82. Renderer source is unchanged. The hosting panel adds shader/preset selection, speed, scale, shape count or distortion, pause, reset, and PNG export.

Read [the included source README](../public/vendor/paper-shaders/README.md), [pinned provenance](../public/vendor/paper-shaders/provenance.json), [Apache license](../public/vendor/paper-shaders/LICENSE), and [required NOTICE](../public/vendor/paper-shaders/NOTICE).

Both require WebGL2. If it is unavailable, Atlas displays an availability message. The original shaders are not replaced by a different renderer. The imported code makes no external runtime requests and contains no photographs or separately sourced texture files.
