# Data and privacy

Motion Atlas processes your inputs in your browser. The public app uses local storage for preferences and has no account system or analytics integration.

## Preferences

Upvotes, downvotes, and notes are saved in this browser for this website address. They stay there until you clear them or browser storage is removed. Someone using the same browser profile can see them. A different website address, browser, or device has its own saved preferences.

Use export/import to move your preferences. The clear-preferences control removes them from the current browser. Downloaded files and shared copies remain wherever you saved or sent them. Storage restrictions or private browsing can prevent preferences from saving; the app reports a save error if this happens.

## Recipe input and local files

Pasted input and opened files are read in browser memory and stay in the browser. Code is displayed as text and never executed. Files are limited to 128 KiB each, with additional limits for each recipe.

Reloading the page clears editor drafts. Download the input or project ZIP to keep your edits. A customized project ZIP contains your input, and a preference export contains your votes and notes. Review these files before sharing them.

## Interactive studies and Music Lab

Study controls and the attention input are processed locally. Most study state lasts only while that study is open. The Markov example stores its transition matrix, random seed, and path position in this browser; **Reset all** restores its defaults.

Music Lab synthesizes sound on your device after an explicit Play action. It does not request microphone access or upload recordings. Melody patterns stay in memory; Save JSON preserves an editable copy and Save WAV exports a synthesized cycle. Imported melody files are validated locally. Study-state and melody downloads may contain your edits, so review them before sharing.

## Links and hosting

Scene and embed links select a gallery scene or supplied recipe example. To share a custom example, send the downloaded input or project ZIP.

The host receives requests for the page and its files, including the URL you visit, and may record them in access logs. External links, such as the GitHub repository or Motion Canvas documentation, open services with their own privacy practices.

If you host a modified version, update this page to describe what it collects or sends.
