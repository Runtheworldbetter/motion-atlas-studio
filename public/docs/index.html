A browser workbench for explanations you can play, inspect, and adapt. Start with cricket, AI, or an editable recipe, then follow the source all the way down.

Explore the cricket strokeExplore AI post-training

Motion Atlas includes the editor, examples, coaching tools, and documentation. Motion Canvas is one of its underlying engines; its developer resources are collected below.

01Get started

  1. Choose a recipe. The Editor tabs cover Cricket, Post-training, Event trace, Waterfall, Code diff, Harmonics, and Pathfinder.
  2. Inspect the explanation. Play, pause, scrub, or slow it down. Use stage buttons where available to pause at a named moment.
  3. Change an input. In an editable recipe, select a preset or open a local file, edit its input, and choose Render changes. Inspect values shows the numbers behind the scene.

The Collection contains 50 gallery examples. Use categories and search to explore them. Votes and notes in Your picks stay in the current browser.

Reference videos behind the revision

We inspected public storyboard samples at one- or two-second intervals from these coaching videos, using side and front views to study posture and movement sequence. This was a sampled reference study, rather than continuous playback or motion capture.

  • Cricket Australia · Steve Smith Masterclass: Straight drive — front / side-oblique at 0:00–0:22, then front / bowler-end after 0:24.
  • Lord’s · Ian Bell cover-drive coaching — side-on at 0:24–0:28 and front-oblique at 0:32–0:35. Used for drive sequencing, not the straight drive’s bat direction.
  • CoachCricXI · HOW to DRIVE — front-on at 0:50–1:28 and side-on at 2:54–3:10.

The authored revision plants the front foot before contact, carries the hands and bat through contact, and lets the shoulder turn settle into a softer finish. Its timing is designed for a clear generic explanation. No source frames or video files are included in Atlas.

03AI: see what reward teaches

The Post-training recipe follows three possible reply strategies and their probabilities. Change the reward scores to see how a small computed policy changes its preference.

  1. Start with Reward evidence. Step through Before, Reward, Update, and After.
  2. Choose Reward confidence. The starting probabilities stay the same; the supplied scores change.
  3. Choose Give equal rewards. The update leaves the probabilities unchanged.

The percentage labels use the calculated probabilities. The 100 dots use rounded shares that always total 100. Inspect values lists each update, its expected reward, and the logit gradient.

This is a single-prompt, three-action policy-gradient model with supplied rewards. It makes one update rule visible; it is not a simulation of all the processes used to train a language model.

05Run and customize

Install Node.js 22.13 or newer and npm, then clone the Atlas. No API keys or database setup are needed.

git clone https://github.com/Runtheworldbetter/motion-atlas-studio.git
cd motion-atlas-studio
npm ci
npm run dev

Open the local address printed by Vite. A downloaded source ZIP works the same way after extraction; start with npm ci.

Check and build a change

npm test
npm run typecheck
node scripts/generate-notices.mjs --check
npm run build
npm run preview

The build produces a static site in dist/, including these docs, dependency notices, and a downloadable source ZIP. It can run at a domain root or a subdirectory such as a GitHub Pages project.

To add a recipe, start with a neighboring definition in lib/recipes/, keep calculations in a pure input model, and register it in the recipe catalog. Follow the contribution guide for validation and review.
