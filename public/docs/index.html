Know exactly what is included

Setosa’s licensed article and diagrams are included. Its separate full playground is linked only, because a reuse grant for that separate application was not verified. Red Blob’s diagrams use plain grids: StarRaven illustrated-map assets are excluded and Conrec is not used at runtime. Paper’s renderers and presets are original; the surrounding standalone controls are Atlas code.

Each package includes readable source, its README, pinned provenance, full licenses and applicable build instructions. Keep those notices when reusing or redistributing a package. Atlas’s MIT license applies to Atlas-authored code and does not replace upstream Apache-2.0, MIT, CC0, font or data terms.

Run an original comfortably

Spectrogram and Sound Waves need WebGL; Sigma and Paper need WebGL2. Red Blob’s selected diagrams use Canvas 2D. Unavailable graphics produce an explanatory message for the original, while source and full-size links remain available. Setosa keeps its original wide article layout and animation; use Open full size for reading. The originals retain their own interaction patterns and do not share the Atlas studies’ export or accessibility features.

The packaged originals load their runtime resources locally, without inherited analytics or remote fonts. Spectrogram’s optional microphone and dropped sound files are processed in the browser. Creator/source links open only when selected. The mechanical watch, shuttle and Voyager experiences are not included.

Repair is a filterable capability

The Can suggest repairs checkbox finds studies that propose changes you can inspect before applying. It is independent of category. In this release it selects Suggest a repair.

  1. Grow the visible stencil from a seed, then remove cells or choose Make a gap.
  2. Choose Propose repairs. A candidate must be inside the stencil and have at least two live orthogonal neighbours.
  3. Read each candidate’s support count, select the repairs you want, then Apply selected. Only selected, currently supported cells change.
  4. Propose again to inspect newly supported cells. Unsupported gaps remain empty.

An inspectable local-rule example. This study uses a known stencil and deterministic rules. Its support counts are not learned confidence scores, and it does not contain a trained neural cellular automaton.

Open a study directly

Use Copy link in the detail view, or link to a fragment such as #explore/repair or #explore/transformer. A link selects the study; it does not serialize edited inputs. Download data records the current model state.

Download frame saves the primary illustration as SVG; the material study exports PNG with either its WebGL or Canvas 2D renderer. Download data saves an inspectable JSON snapshot. General import of those study snapshots is not provided in this release.

The Markov study remembers its matrix, seed, and path position on this device without starting playback. Other studies generally keep controls only while their detail view is open. Use Reset all in the Markov study to restore defaults.

04Music Lab: hear the model

Music Lab has seven tabs sharing one active experiment surface. Three are Atlas experiments; four are faithful, self-hosted Chrome Music Lab originals. Labels identify their source. Atlas audio starts with Play; the originals unlock audio on a pointer, touch, or key gesture and use their original instrument controls. No account is required. Spectrogram offers an optional microphone; the other modes need no microphone access.

Switching experiments or hiding the page stops audio. An upstream original unloads on switch or page hide. Use Start experiment after it stops; reopening starts a fresh instance. Its files are served locally from Atlas; the four originals make no external runtime requests.

Sound Waves and Spectrogram require WebGL. When the original renderer cannot initialize, the experiment displays an availability message and relevant source or full-size links. This is separate from the Atlas material study’s Canvas 2D fallback.

In the melody grid, columns are time and rows are pitch. Each step is half a beat. Use arrow keys to move between cells and Space or Enter to toggle a note. The 16-step grid scrolls on small screens.

Keep the composition and the sound

In Atlas’s Make a melody, Save JSON preserves an editable pattern; Import JSON validates and restores it without starting audio. Save before reloading because compositions are held in page memory. Save WAV renders one complete cycle using the current pattern, tempo, timbre, and listening level. These exports and keyboard composition controls belong to Make a melody; the upstream originals keep their own instrument controls.

The WAV is mono 16-bit PCM at 22,050 Hz. Looping does not lengthen the downloaded cycle. JSON imports must be smaller than 32 KB and contain five boolean pitch rows, an 8- or 16-step length, tempo, timbre, and format version.

If Web Audio is unavailable, Atlas’s visual models and melody downloads remain usable. The resting waveform is a labelled model preview; the live spectrum comes from the generated audio while playing.

The three Atlas experiments are inspired by Chrome Music Lab. The four originals include upstream code and assets from revision e54bb414, retaining Apache-2.0 and third-party notices. Read the earlier instruments’ provenance and licenses, Spectrogram’s source and integration guide, or Atlas’s controls and complete melody JSON format.

Reference videos behind the revision

We inspected public storyboard samples at one- or two-second intervals from these coaching videos, using side and front views to study posture and movement sequence. This was a sampled reference study, rather than continuous playback or motion capture.

  • Cricket Australia · Steve Smith Masterclass: Straight drive — front / side-oblique at 0:00–0:22, then front / bowler-end after 0:24.
  • Lord’s · Ian Bell cover-drive coaching — side-on at 0:24–0:28 and front-oblique at 0:32–0:35. Used for drive sequencing, not the straight drive’s bat direction.
  • CoachCricXI · HOW to DRIVE — front-on at 0:50–1:28 and side-on at 2:54–3:10.

The authored revision plants the front foot before contact, carries the hands and bat through contact, and lets the shoulder turn settle into a softer finish. Its timing is designed for a clear generic explanation. No source frames or video files are included in Atlas.

06AI: see what reward teaches

The Post-training recipe follows three possible reply strategies and their probabilities. Change the reward scores to see how a small computed policy changes its preference.

  1. Start with Reward evidence. Step through Before, Reward, Update, and After.
  2. Choose Reward confidence. The starting probabilities stay the same; the supplied scores change.
  3. Choose Give equal rewards. The update leaves the probabilities unchanged.

The percentage labels use the calculated probabilities. The 100 dots use rounded shares that always total 100. Inspect values lists each update, its expected reward, and the logit gradient.

This is a single-prompt, three-action policy-gradient model with supplied rewards. It makes one update rule visible; it is not a simulation of all the processes used to train a language model.

08Run and customize

Install Node.js 22.13 or newer and npm, then clone the Atlas. No API keys or database setup are needed.

git clone https://github.com/Runtheworldbetter/motion-atlas-studio.git
cd motion-atlas-studio
npm ci
npm run dev

Open the local address printed by Vite. A downloaded source ZIP works the same way after extraction; start with npm ci.

Check and build a change

npm test
npm run typecheck
node scripts/generate-notices.mjs --check
npm run build
npm run preview

The build produces a static site in dist/, including these docs, full notices, a complete source ZIP, and six individual original-source ZIPs under originals/. It can run at a domain root or a subdirectory such as a GitHub Pages project.

To add a study, start in src/labs/, keep calculations under lib/explorations/, and register its category, capabilities, basis, and inspiration in lib/explorations/catalog.ts. For a recipe, use lib/recipes/ and the recipe catalog. Follow the contribution guide for validation and review.

Original adaptations and licensed originals

The 15 studies and three Atlas music experiments use original Atlas code, synthetic examples, authored geometry, and sound/shader models. Each study links to its independent teaching or design references. The card-to-detail interaction is inspired by Motion Primitives. The six new projects in Originals and four Google Music Lab instruments are labelled upstream work with their own code and retained licenses. Spectrogram appears in both collections.

The three restored New Directions modules remain Atlas-authored work under MIT. Their venue note, book collection, reading hours, and word sequence are fictional or illustrative; no private source materials are included.

The small models state their boundaries: the attention study is not a trained language model; repair uses explicit local rules; the projectile ignores air resistance. Open each study’s model notes before extending its conclusions. The spacecraft study was removed in 0.5.1; the original Voyager experience is omitted because an applicable reuse or embedding grant could not be verified.
